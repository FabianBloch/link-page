# Bilder für Links

Hier können Bilder für die Links hinzugefügt werden. Es wird empfohlen, Bilder mit einer Größe von 100x100 Pixeln zu verwenden, um eine optimale Darstellung auf der Seite zu gewährleisten. Die Bilder sollten im `images`-Ordner gespeichert und in der JSON-Struktur mit dem entsprechenden Pfad angegeben werden. Zum Beispiel:

```json
{
  "title": "Google",
  "url": "https://www.google.de",
  "desc": "Die weltweit führende Suchmaschine",
  "image": "images/google.png",
  "tag": "suche, web",
  "color": "blue"
}
```
